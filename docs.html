Installation

Installer les dépendances puis compiler le SCSS :

npm install
npm run sass:build   # compile une fois
npm run sass:watch   # recompile à chaque modification

# ou directement, si sass est installé :
sass scss/main.scss css/main.css

Puis lier la feuille de style compilée dans votre page :

<link rel="stylesheet" href="css/main.css">

Architecture (SMACSS)

DossierRôle
abstract/Variables et mixins. Ne génère aucun CSS.
base/Reset et styles des balises HTML (aucune classe).
layout/Conteneur et grille de 12 colonnes.
modules/Composants réutilisables : bouton, carte.
state/États : .is-disabled, .is-hidden.
theme/Habillage des pages de démo et de documentation.

Le nommage suit la notation BEM : .bloc, .bloc__element, .bloc--modificateur.

Grille

La grille repose sur flexbox et 12 colonnes. Placez des colonnes .col-1 à .col-12 dans une .row, elle-même dans un .container. La somme des colonnes d'une ligne doit faire 12. Les colonnes sont séparées par une gouttière de $grid-gutter. Les classes sont générées par le mixin make-grid(), qui appelle make-col() dans une boucle @for.

col-8
col-4
col-3
col-6
col-3
<div class="container">
  <div class="row">
    <div class="col-8">col-8</div>
    <div class="col-4">col-4</div>
  </div>
  <div class="row">
    <div class="col-3">col-3</div>
    <div class="col-6">col-6</div>
    <div class="col-3">col-3</div>
  </div>
</div>
ClasseEffet
.containerCentre le contenu, largeur max $container-max-width.
.rowLigne flex qui contient les colonnes et compense leur gouttière.
.col-1 … .col-12Occupe N colonnes sur 12, avec une demi-gouttière de chaque côté.

Boutons

Ajoutez toujours la classe de base .btn, puis un modificateur de couleur et éventuellement un modificateur de taille. Fonctionne sur <a> et <button>. Au survol et au focus clavier, le bouton s'assombrit pour signaler qu'il est cliquable.

Primaire Secondaire Petit Grand 
<a href="#" class="btn btn--primary">Primaire</a>
<a href="#" class="btn btn--secondary">Secondaire</a>
<a href="#" class="btn btn--primary btn--sm">Petit</a>
<a href="#" class="btn btn--primary btn--lg">Grand</a>
<button class="btn btn--primary" disabled>Désactivé</button>
ClasseTypeEffet
.btnBlocStructure commune (obligatoire).
.btn--primaryModificateurBouton principal (couleur $color-primary).
.btn--secondaryModificateurBouton secondaire (couleur $color-secondary).
.btn--smModificateurPetit bouton.
.btn--lgModificateurGrand bouton.
.is-disabled / disabledÉtatBouton désactivé.

Cartes

Une carte .card peut contenir tout ou partie des éléments suivants : une image, un titre, un texte et un bouton. Les éléments absents peuvent simplement être retirés du HTML.

Carte complète

Image, titre, texte et bouton.

Bouton

Sans image

Titre, texte et bouton.

Bouton

Image et texte seulement.

<div class="card">
  <img class="card__img" src="image.jpg" alt="Description">   <!-- optionnel -->
  <div class="card__body">
    <h3 class="card__title">Titre</h3>                  <!-- optionnel -->
    <p class="card__text">Texte de la carte.</p>          <!-- optionnel -->
    <a href="#" class="btn btn--primary card__btn">Bouton</a> <!-- optionnel -->
  </div>
</div>
ClasseTypeEffet
.cardBlocConteneur de la carte.
.card__imgÉlémentImage en haut, hauteur $card-img-height.
.card__bodyÉlémentZone de contenu avec marges internes.
.card__titleÉlémentTitre de la carte.
.card__textÉlémentTexte de la carte.
.card__btnÉlémentÀ ajouter sur un .btn : le place en bas de la carte.

Variables et mixins

Toutes les valeurs sont définies dans scss/abstract/_variable.scss. Modifiez-les pour personnaliser le framework.

VariableValeur
$color-primary#4f46e5
$color-secondary#f59e0b
$color-primary-dark, $color-secondary-darkCalculées à partir des deux couleurs ($btn-hover-darken : -15 %).
$grid-columns12
$grid-gutter1.5rem
$container-max-width1140px
$spacing-xs … $spacing-xl0.25rem … 3rem
$border-radius8px

Mixins disponibles (scss/abstract/_mixin.scss)

MixinUsage
make-grid($columns)Génère les classes .col-1 à .col-12 avec une boucle @for.
make-col($size, $columns)Donne à un élément la largeur de $size colonnes et sa gouttière.
hover-focusApplique le bloc reçu (@content) au survol et au focus clavier.
button-variant($bg, $color, $bg-hover)Crée une variante de couleur de bouton, avec son effet au survol. $bg-hover est optionnel.
button-size($py, $px, $font-size)Crée une variante de taille de bouton.
flex-centerCentre le contenu avec flexbox.
// Exemple : créer un bouton "danger"
.btn--danger {
  @include button-variant(#dc2626);
}

// Exemple : souligner un lien au survol et au focus
.lien {
  @include hover-focus {
    text-decoration: underline;
  }
}
